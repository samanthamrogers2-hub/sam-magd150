# MAGD-150 Portfolio

This repository contains projects and assignments created for MAGD-150 using p5.js.

## Assignments Included

### Lab 1
Introduction to p5.js drawing tools and shapes.

### Lab 5
Interactive animation using variables and movement.

### Final Project - Runway Remix
An interactive fashion dress-up game created with p5.js. Users can customize outfits, backgrounds, and activate a runway animation mode.

## Skills Demonstrated
- Animation
- User Interaction
- Arrays
- Functions
- Conditional Statements
- Visual Design
- Creative Coding
